Design System

Portfolio Typography and Color System

Typography Scale

Heading 1 – Portfolio Title

Heading 2 – Section Titles

Heading 3 – Subsections

Body text is used for descriptions and paragraphs across the site. The goal is readability, clear hierarchy, and consistent spacing.

Caption / small text example
  • H1: 48px
  • H2: 32px
  • H3: 24px
  • Body: 16px
  • Caption: 14px

Font Choice

This site uses a clean sans-serif font to prioritize readability and modern design. Using one font family with multiple weights helps maintain visual consistency across pages while still creating hierarchy between headings and body text.

  • Primary Font: Inter / System Sans-Serif
  • Weights: Regular, Medium, Bold

Color Palette

  • #1A1A1A – Primary text color
  • #FFFFFF – Background
  • #4A6FA5 – Accent / links
  • #D9E2EC – Section backgrounds
  • #F5F7FA – Light background

Accessibility

The color palette prioritizes contrast between text and background to meet accessibility standards. Dark text is used on light backgrounds to ensure readability. Links use the accent color and include hover states for clarity.

Usage Across Pages

The design system ensures consistent styling across the portfolio including the homepage, project pages, and about section. The type scale maintains hierarchy and the color palette provides a unified visual identity.
