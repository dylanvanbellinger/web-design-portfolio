Caption / small text example

  • H1: 48px, line-height 1.15

  • Caption: 14px

Font Choice

This site uses a clean sans-serif font (system-ui) to prioritize readability and fast loading. Using one font family with multiple weights keeps pages consistent while still creating hierarchy.

  • Primary Font: system-ui (fallbacks: -apple-system, Arial, sans-serif)
  • Weights: Regular, Medium, Bold

Accessibility

  • High contrast: dark text on light background for readability
  • Links have clear states (default, hover, visited)
  • Keyboard focus uses :focus-visible outline for navigation

Usage Across Pages

This design system is applied site-wide through shared CSS variables and the type scale, ensuring consistent styling on the homepage, about page, and project pages.
