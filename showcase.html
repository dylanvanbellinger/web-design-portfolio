Portfolio Website Project

A responsive personal portfolio built using HTML, CSS, and GitHub Pages.

Project Overview

This project is a fully responsive personal portfolio website designed to showcase my work, experience, and creative projects. The goal was to build a clean and professional website that communicates my personal brand and makes it easy for visitors to understand my skills and work.

Concept & Audience

The site was designed for recruiters, collaborators, and potential employers who want a quick overview of my professional experience. The layout prioritizes clear navigation, visual hierarchy, and readability so users can quickly navigate between sections such as projects, experience, and contact information.

Site Structure

Homepage

The homepage introduces my portfolio and provides a brief overview of my background, interests, and work. It includes navigation links to other pages and a short introduction explaining the purpose of the site.

Interior Pages

The interior pages include an About page, Portfolio page, and Contact page. These pages provide more information about my background, showcase project work, and give visitors a way to connect with me professionally.

Interactive Element

The homepage includes a simple interactive feature using JavaScript. A “Read More” button reveals additional information when clicked, allowing users to expand content without overwhelming the page layout.

Tools Used

  • VS Code
  • HTML & CSS
  • Figma
  • GitHub
  • GitHub Pages
  • Chrome DevTools
  • WAVE Accessibility Checker

Reflection

Through this project I learned how to design, build, and refine a responsive website from concept to launch. I practiced writing semantic HTML, creating consistent visual styling with CSS, and testing usability across mobile, tablet, and desktop devices. I also gained experience using GitHub for version control and deployment. This project helped me understand how design, structure, and accessibility all work together to create a strong user experience.
